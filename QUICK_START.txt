# ⚡ Quick Start - 2 Steps to Live Data

## Step 1️⃣: Start Flask Server
```bash
cd "f:\GUNAL 2025\HARDWARE PROJECT 2025-26\SOIL_CROP_ECOM\SENSOR DATA READ 3.10.0"
python main.py
```

Wait for this message:
```
🟢 AI Smart Agriculture System Started
```

---

## Step 2️⃣: Open in Browser
```
http://127.0.0.1:5000
```

---

## ✅ What You'll See

1. **Connection Status** (top of page)
   - Green ✅ = Connected to sensors
   - Yellow ⚠️ = Test mode (no sensors, showing simulated data)
   - Red ❌ = Connection error

2. **Live Data Cards**
   - Temperature, Humidity, Moisture
   - Nitrogen, Phosphorus, Potassium
   - **Soil pH** (NEW!)
   - Soil Status prediction

3. **3 Live Charts**
   - Temperature trend
   - Humidity trend  
   - Moisture trend

4. **All Updates Every 5 Seconds**

## 📱 From Other Devices?

Find your IP (on Windows terminal):
```bash
ipconfig
```

Use that IP: `http://YOUR_IP:5000`

Example: `http://192.168.1.100:5000`

---

## ❓ Have Sensors?

Make them send UDP to port **4210**:

Format: `temp,hum,light,moisture,pH,N,P,K`  
Example: `25.5,65,450,70,6.8,45.2,38.5,52.1`

System will automatically detect real data within 10 seconds.
