# 🌱 Smart Farming Dashboard

## 📌 Project Overview
The Smart Farming Dashboard is a web-based application that helps farmers monitor and manage agricultural activities efficiently. It provides crop monitoring, weather updates, soil information, irrigation status, and farming analytics in a single dashboard.

## ✨ Features
- 🌦️ Weather Monitoring
- 🌱 Crop Health Monitoring
- 💧 Irrigation Management
- 🌍 Soil Moisture Tracking
- 📊 Dashboard Analytics
- 🔐 Secure User Login
- 📱 Responsive Design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Python (Optional Backend)
- Flask (Optional)
- Chart.js
